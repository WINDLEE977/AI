# 그림AI 내비 — 설치형 웹앱(PWA) 안내서

이미지 생성 AI 11개를 비교하고, 용도에 맞는 AI를 추천해 주는 모바일 앱이에요.
앱스토어 없이 무료 웹 공간에 올려서, 아이폰과 갤럭시 홈 화면에 아이콘으로 설치해 씁니다.

---

## 1. 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 모든 정보(AI 목록, 가격, 장단점, 추천 규칙)가 들어 있는 본체 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체 화면으로 열기 같은 "앱 신분증" |
| `sw.js` | 인터넷이 없어도 열리게 해 주는 저장 담당(서비스 워커) |
| `img/` | 같은 주문으로 만든 예시 그림 24장 |
| `icons/` | 홈 화면 아이콘 |

---

## 2. 인터넷에 올리기 (GitHub Pages, 무료)

처음 한 번만 하면 돼요. 10분 정도 걸려요.

1. **github.com**에서 무료 계정을 만들어요.
2. 오른쪽 위 **+** 버튼 → **New repository**를 눌러요.
   - 이름: `gai-navi` (원하는 영어 이름 아무거나)
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면의 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 폴더 **안의 내용물 전부**(index.html, sw.js, manifest.webmanifest, img 폴더, icons 폴더, README.md)를 끌어다 놓아요.
   - 주의: 바깥 폴더째 올리면 안 되고, `index.html`이 맨 위에 보여야 해요.
5. 아래 **Commit changes**를 눌러요.
6. 저장소의 **Settings** → 왼쪽 **Pages** → Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**.
7. 1~2분 뒤 같은 화면 위쪽에 주소가 생겨요.
   예: `https://내아이디.github.io/gai-navi/`

> Public 저장소라 주소를 아는 사람은 누구나 볼 수 있어요. 앱에 개인정보는 없으니 괜찮아요.
> 메뉴 이름은 GitHub 화면 개편에 따라 조금 다를 수 있어요.

**더 간단한 대안:** `app.netlify.com/drop`에 폴더를 끌어다 놓아도 돼요. 단, 주소를 계속 유지하려면 무료 계정에 연결해야 해요.

---

## 3. 휴대폰에 설치하기

### 갤럭시 (안드로이드)
1. **크롬** 또는 **삼성 인터넷**으로 위 주소를 열어요.
2. 화면에 뜨는 **설치** 버튼을 누르거나, 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**를 눌러요.

### 아이폰
1. 반드시 **사파리**로 주소를 열어요. (다른 브라우저는 설치가 안 될 수 있어요)
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**.

설치하고 나면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 **인터넷이 없어도** 목록·비교·예시 그림을 볼 수 있어요.

## 4. 기능별로 알아둘 점

| 기능 | 갤럭시 | 아이폰 |
|---|---|---|
| 글로 입력해서 추천 | 됨 | 됨 |
| 마이크 버튼 음성 입력 | 크롬·삼성 인터넷에서 됨 (인터넷 필요) | 사파리 웹에선 대체로 됨. **홈 화면 앱에서는 막힐 수 있어요** → 입력창을 누르고 키보드의 마이크(받아쓰기) 버튼을 쓰세요 |
| 읽어주기 | 됨 | 됨 |
| 오프라인 열기 | 됨 | 됨 |

**추천 방식:** 이 버전은 Claude 없이 동작하도록, 적어 주신 문장 속 단어(무료, 포스터, 로고, 인물, 영상 등)로 골라요. 조건을 구체적으로 적을수록 정확해요.

## 5. 정보 고치는 법 (가격이 바뀌었을 때)

1. `index.html`을 메모장이나 VS Code 같은 편집기로 열어요.
2. `const APPS = [` 아래에 AI별 정보가 있어요. 예:
   ```
   free:"하루 2~3장 정도", paid:"Plus 월 $20",
   ```
   따옴표 안의 글자만 바꾸고, 따옴표와 쉼표는 지우지 마세요.
3. `sw.js`를 열어 맨 위의 `const VERSION = "v1";`을 `"v2"`처럼 **숫자를 하나 올려요.**
   - 이걸 안 하면 이미 설치한 폰에 예전 정보가 계속 보일 수 있어요.
4. GitHub 저장소에서 바뀐 두 파일을 다시 끌어다 올리고 **Commit changes**.
5. 폰에서 앱을 한 번 열었다 닫았다 하면 새 버전으로 바뀌어요.

**추천 규칙 고치기:** `index.html`의 `const KW=[`(어떤 단어를 어떤 조건으로 볼지)와 `const FIT=`(조건별 AI 점수, 0~3)를 고치면 돼요.

**날짜 표시:** 화면의 "2026년 10월 기준" 문구는 `const UPDATED = "2026년 10월";`과 하단 문구에서 바꿔요.
